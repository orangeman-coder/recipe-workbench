设置

大模型由你自行配置（OpenAI 兼容接口），菜谱库支持从 ima 知识库导入。

提示：多数服务商不允许浏览器直连（CORS 限制）。本地使用请先在 recipe-workbench 目录运行 node server.js 并访问 http://127.0.0.1:8787/；部署到 Vercel 后自带 /api 代理，手机浏览器直接可用，无需任何本地程序。

同步流程：连接 ima → 选择订阅的知识库 → 拉取菜谱内容 → 由已配置的文本模型解析为结构化菜谱并导入本地库（此后检索离线进行，不再访问 ima）。若浏览器直连被跨域（CORS）拦截，可把 Client ID / API Key 提供给 WorkBuddy 助手，由本地代理完成同步。

高级：手动导入 / 导出 JSON

格式：[{"n":"菜名","m":[["食材","数量"]],"s":["调料"],"st":["步骤"],"min":15,"d":"简单","t":["炒锅"],"c":"中餐","tg":["标签"]}]，未知字段会被丢弃。
